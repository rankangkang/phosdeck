## 已知问题

- **合成预览耗时**：距离匹配已按描述子维度批量向量运算并复用双向距离，保留原 L2、严格比值与首个同距规则；同源受控匹配点及顺序一致，相关回归已核对。固定体验 App 已核对全景预览、DNG 保存入库及继续编辑；同源同选项的优化前后母版 RGB 与透明度逐位一致，来源文件与旧母版未改写。完整 Debug 预览仍较慢，特征提取和融合的其余耗时待分段测量；实窗计时受捕捉中断影响，只保留观察区间，不作整体加速比例结论。其余性能优化仍暂缓，效果待用户验收。
- **预览**：原一秒卡顿根因未证实（drawable 默认一秒超时只是候选，相关等待已移出主线程）；质量图计算完到发布仍有约 0.1 秒主线程等待。严格同条件前后对照、物理屏幕呈现、长时间拖动帧率、大 RAW 与 Release 实窗都未测。继续时先在无 AX 遍历干扰的交互区间做 CPU 与主线程等待采样。
- **既有源坐标逆映射**：合成浮点梯度检查显示 `PhotoGeometry`／`MaskGeometry.sourcePoint` 在四分之一旋转为 1 或 3 时，与实际渲染像素的位置不同；未改既有渲染、旋转或蒙版模型。新目标调整直接取同一输出几何的浮点参考图，并以原生输出核对位置；其他工具的逆映射差异待单独定位。
- **偶发测试失败**：`ComparisonTests.testAdjustmentReturnEndsEditingAndDoesNotReapplyAnUndoneValue` 多次在首次全量中失败、单跑通过，根因未定位；测试期间切换窗口可能影响焦点。
- **预设测试的语言假设**：`PresetManagementTests.testUnicodeSearchFavoriteAndMultipleGroupsFilter` 将中文分组顺序写成固定期望，英文环境的收藏排序断言失败、中文通过；筛选和排序实现未改，测试的语言假设待处理。
- **模型资源复制测试**：`SmartMaskTests.testOptionalModelCapabilitiesAndPartialBundleCopies` 仍会因测试宿主沙箱拒绝 `ditto` 的 `.BC.T_*` 临时文件而失败；对应脚本与测试未改动，具体触发机制未定位。
- **测试环境**：免证书临时签名仍有权限身份随构建变化及 hardened runtime 关闭的限制；本机已统一稳定开发签名，后续实际测试是否仍有授权弹窗待观察。外置卷上的测试宿主、失败符号化及内置宿主读取外置仓库夹具曾停在 `__open`；内置盘暂存继续沿用同一路径，已能执行未过滤标识的全量原生检查；外置宿主路径与偶发夹具读取长等待仍待单独核对。
- **应用分发**：本机已配置 Developer ID Application 证书；[`0.1.0-alpha.1`](https://github.com/rankangkang/phosdeck/releases/tag/v0.1.0-alpha.1) 已作为预发布公开，签名、公证、票据、`spctl` 评估及下载 ZIP 已核验。独立环境中的安装、启动与使用体验尚未验证。
- **智能蒙版模型**：FaceParsing 权重标注 MIT，训练数据条款对权重分发的适用性尚不明确；LiteRT 预编译包的完整依赖清单与正式模型安装／分发方案仍待核对，见 [模型说明](smart-mask-models.md)。
- **普通图像曝光响应表**：按用户决定保留现有表、显影行为与对照资料。[Adobe 通用条款第 17 节](https://www.adobe.com/legal/terms.html)限制为重建软件而跟踪输入与输出；当前表由 Lightroom 输出拟合，具体合同与法律适用尚未判定。数值对照见[现行 TIFF 比较](references/lightroom-exposure-v4-comparisons.json)与[JPEG 分区表](references/lightroom-exposure-v4-jpeg-regions.csv)，来源资料和公开使用依据仍须核对。
- **JPEG 对照**：JPEG 导入、编辑及导出已有支持，大曝光下与 Lightroom 的差异仍未解决。静态调查只确认 CameraRaw 内部的 JPEG→CGImage 桥接，未连到最终显影／导出与曝光 stage；完整 Ghidra 分析超时，不能据此改响应表或推断最终管线。
- **日志**：构建与测试日志反复出现 `MDB_MAP_FULL`，来源未定位。
- **验证工具**：系统设置的应用语言移除控件在 CUA 中可能出现 AX 句柄失效，坐标回退也可能报 `noWindowsAvailable`，需保留手动操作途径。Lightroom 合成目录窗口手动从 Dock 恢复后，主窗口 REA 观察与画布坐标拖动已可用；自绘直方图自动拖动仍无变化，REA 匹配临时对话框可能报 `window-mismatch`，CUA 仍可读取其选项。CUA 不支持普通指针移动，hover 需人工检查；关闭设置后可能持续读取超时，正常退出并重开固定体验 App 可恢复；按固定 bundle ID 重新取得绑定并置前主窗或从 Dock 恢复也曾有效，根因未确认。相机诊断的离屏截图偶发漏绘保存按钮文字，双主题实窗显示正常。退出参考模式后照片信息条曾在米白窗口截图中漏绘，用户确认同一窗口实际屏幕上的相机名与拍摄参数完整可见，本次确认是捕捉遗漏；不能仅凭截图缺字修改 App。

## 下一步与候选

- **Agent 接入第三步**：按[执行方案](agent-integration.md)接入图库创建与切换、原生文件授权、导入与冲突处理，以及任务状态、取消和恢复。

Lightroom 功能补齐第一批（匹配总曝光、直方图拖动、图上目标调整）、第二批文件夹差异预览、第三批自动白平衡／自动色调及手动去边已实现原生版本，运行对照与未测边界见待用户验收。交互参考本机 Classic 15.2.1 安装资源和 Adobe 公开说明，未恢复 Adobe 算法。以下保留候选，沿用 [已定决策](decisions.md) 中的不做与暂缓范围。

- **外部编辑往返（用户暂缓）**：参考 [外部编辑](https://helpx.adobe.com/lightroom-classic/desktop/work-with-external-editors/open-lightroom-photos-external-applications.html)。复用 TIFF16 导出生成派生文件、交给外部 App，再核验并作为独立来源入库关联；文件生命周期、身份与中断恢复须单独设计。
- **离线可编辑代理（用户暂缓）**：参考 [Smart Previews](https://helpx.adobe.com/uk/lightroom-classic/desktop/viewing-photos/lightroom-smart-previews.html)。已有缩略图／预览缓存，原片不可用时仍缺编辑代理；须定义代理格式、来源身份、RAW 基准、重连核验和最终输出规则。

- 智能蒙版：用户体验现有功能后，再决定对象请求队列、跨照片部位缓存和逐人索引持久化。
- 模型分发：确认训练数据条款对现有 FaceParsing 权重的适用性，或更换授权依据清晰的权重；补齐运行时依赖声明并确定安装方式。
- 继续编辑工作区细节打磨：尚未覆盖的工具和局部面板长文案。
- 工作流：快照创建撤销、集合组；内容感知填补、物理文件管理为后续大项。
- 应用分发：验证下载安装与使用体验，核对发行说明和随包许可。
