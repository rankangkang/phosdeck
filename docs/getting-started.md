# 上手指南

Phosdeck 目前处于开发预览阶段。首次体验建议使用合成图片或有权使用的照片副本，并将照片、图库和导出目录分开存放。源码构建见 [README](../README.zh.md#快速上手)。

应用中的“目录”指 `.phoscat` 图库数据库，只保存照片路径、整理信息与非破坏性调整；原片始终独立保存在照片文件夹中。

## 连接 Agent

1. 安装 [Phosdeck Skill](agent-integration.md#安装-phosdeck-skill)，并在“设置 → Agent”开启“本地 MCP 服务”；需要让客户端查看图像时再单独开启“共享照片预览”。
2. 点击“复制 JSON 配置”（适用于 `mcpServers` 客户端）或“复制 Codex 配置”＋“复制令牌”（注入对应环境变量）。服务重启后须重新复制配置与令牌。[本地连接](agent-integration.md#本地连接)
3. 客户端连接后先调用 `get_capabilities` 与 `get_workspace` 核对应用和图库身份，即可进行导入、筛选、整理、全局与局部显影、多帧合成、多规格导出及图库维护；文件授权与不可逆确认由 Phosdeck 原生面板完成。[Agent 接口说明](agent-integration.md)

## 1. 新建与打开图库

1. 选择“文件 → 新建目录…”创建 `.phoscat` 文件并按系统提示授权所在文件夹，或通过“打开目录…”／访达双击／“打开最近使用的目录”打开已有图库。
2. 打开旧后缀 `.omlcat`／`.omlrcat` 时，可选择“更换后缀并打开”（原位置无覆盖改名为 `.phoscat`，不改内部数据）、“保持原名打开”或“取消”。
3. 可通过“文件 → 从 Lightroom Classic 目录导入…”将 `.lrcat` 转换为新 `.phoscat`，或单独导入 Lightroom XMP 预设。

## 2. 导入照片与文件夹差异

1. 点击“导入…”选择照片文件夹及是否包含子文件夹，顶部选择导入方式：
   - **添加**：原地引用，图库仅记录位置；后续访问须保持原目录可用。
   - **复制**：将所选照片（及可选 XMP／ACR 附件）复制到目标目录并入库，保留来源文件，同名冲突按提示处理。
2. 支持单击、`Shift` 连选、`⌘` 多选、`⌘A` 全选、`⌘D` 取消选择，空格键或点击勾选键批量勾选所选组。“所有照片”默认压暗并取消勾选已入库与疑似重复项；“新照片”随扫描动态追加。
3. **支持格式**：JPEG、RGB TIFF（多页仅预览首页）、静态 PNG、静态 SDR、PQ 与 HLG HEIC／HEIF／HIF，以及部分 ARW／SR2／DNG／NEF／NRW／CR2／CR3／RAF／ORF／RW2／RWL／PEF／3FR／FFF／SRW（是否可解取决于具体文件与 macOS）。Apple DNG 已验证 iPhone XS 传感器 DNG 与 iPhone 12 Pro 线性 DNG；动态 HEIF 暂未开放。未调整 RAW 有机内预览时，网格与胶片带先显示机内预览，适窗停留后切回原生 RAW 显影。
4. **查看文件夹差异**：右键侧栏根／子文件夹选择“查看文件夹差异…”只读预览新增、缺失、变更、疑似移动、需检查与已移除版本（默认全不勾选）；确认时整批原子写入，不移动、替换或删除原片，也不删除缺失记录。原片回到原位且校验一致时可恢复可用状态或已移除版本。

### 从 Lightroom Classic 目录导入

1. 退出 Lightroom Classic，选择“文件 → 从 Lightroom Classic 目录导入…”并授权 `.lrcat` 所在目录；缺失原片目录时点击“定位…”。
2. 选择“原地引用”或“复制原片”并指定新图库位置。系统会转换受支持的星级、旗标、色标、关键词、题注、普通集合、虚拟副本、逐步显影历史（含支持的参数、旋转／翻转与裁剪）、RAW 默认镜头校正开关及目录旁 XMP 预设。两者的色彩配置与显影响应可能不同。
3. 项目的 `Lightroom` 文件夹保留源 `.lrcat`、`.lrcat-data`、`Lightroom Settings` 与 `Import.txt` 报告（列出未转换项）。缺片记录可在导入后通过“定位原片”恢复核验。

### RAW 兼容性记录

| 公开样片 | 本机诊断结果 |
|---|---|
| Canon EOS Digital Rebel XT CR2、Panasonic LX7 RW2、Pentax K10D PEF | 可导入并生成 16 位质量图。 |
| Olympus E-10 ORF | Apple 解码尺寸为零。新配方在可用时走 LibRaw 解包与 Metal Bayer 去马赛克，重开按配方中的解码器版本显影。 |
| Hasselblad H3D 3FR | 保留 Apple 后端，可导入并生成 16 位图。本机 256 px 质量图多轮诊断中，新管线及草稿后重算均曾出现最高 17 个 8 位码值的通道差。 |
| iPhone XS 传感器 DNG、iPhone 12 Pro 线性 DNG | 新配方使用 LibRaw，已核对 12 Pro 竖拍方向、独立管线重复显影、草稿后重算与 16 位输出。 |

样片的机型、模式和 SHA-256 见[公开样片清单](../Tests/Fixtures/public-raw-samples.json)。诊断结果限于记录的样片和系统。

## 3. 整理与编辑

### 浏览、筛选、堆叠与移除

- **快捷导航**：`D` 进入编辑、`G` 返回网格原滚动位置、`N` 打开多图甄选（`/` 移出候选）、`⌘A` 全选当前来源及筛选跨页与折叠堆叠匹配项、`⌘Z` 撤销。网格和胶片带优先加载可见缩略图，并在空闲时按滚动方向预热相邻页（低电量或高热自动暂停）。
- **网格与堆叠**：网格顶栏分列去扩展名文件名与独立类型，底栏显示评级、旗标与序号；堆叠通过页首尾细把手或 `S` 键展开／折叠（范围不完整时显示 `匹配数/整组数` 并提示隐藏成员）。支持按拍摄时间自动堆叠，选中含 ≥2 张匹配成员的堆叠可点击“比较本组”连续切组选片（左右键切候选、`↑` 设为参考、`P` 标旗、`⇧S` 设封面）。
- 打开图库“文本”筛选，输入文件名、题注、关键词或虚拟副本名的任意片段。由当前筛选创建智能集合会保留这四项搜索范围。排序菜单还可按标旗、色标、文件扩展名、原片修改时间或原片宽高比排列。修改时间取最近一次核对原片时的记录，宽高比按 EXIF 方向计算，未知值排在末尾。
- 在图库选择“照片 → 从图库移除已排除的照片…”（⌘Delete），核对版本数后确认。当前来源和筛选决定范围，包含其他页和折叠堆叠中的匹配版本。冻结结果时仍以确认时的标旗为准。点击工作区“撤销”可整批恢复，键盘焦点在网格时也可按 ⌘Z。
- **三种移除**：右键或“照片”菜单区分**从此集合移除**（仅取消集合成员）、**从图库移除**（保留原片）和**将原片移到废纸篓**（需选中原版及全部虚拟副本并授权原片目录；恢复时先在 Finder 移回原路径，再用“查看文件夹差异… → 已移除版本”恢复原记录与编辑）。
- **显影历史**：单击历史步骤可直接切换已保存状态并保留完整历史，新调整或应用快照记为新步骤。

### RAW 相机风格

- 编辑 RAW 时，在“基本调整 → 相机风格”打开右侧品牌分组缩略图浏览栏：悬停临时试显，点击保存并新增历史，跨机身切换保留已有调整。
- **RAW 高光预览**：采用 Apple 解码的 RAW 可在编辑模块的显示菜单勾选“以 HDR 预览 RAW 高光”。此选项仅改变预览，导出仍按所选 SDR 色彩空间处理。
- **按拍摄风格**自动识别当前 RAW 拍摄档位，并在存在可用机内预览时进行同帧颜色与影调校准。
- 随包提供富士 18 项固定胶片模拟（加 Nostalgic Neg.、REALA ACE）、索尼 ST 以及根据公开同帧 RAW／JPEG 拟合的佳能 EOS M50、尼康 D750 标准与 D850 标准近似色表（[Redlamp](references/redlamp-LICENSE.txt) · [Fuji Recipe Converter](references/fuji-recipe-converter-LICENSE.txt) · [LightCraft](references/lightcraft-LICENSE.txt)）。如需补齐索尼 α7R V 其余 9 项，可用 `python3 scripts/pack-sony-local-looks.py Sony-A7R-V-Creative-Looks.zip CameraLooks`（需 NumPy）生成色表目录放入 App 容器 `Data/Library/Application Support/OhMyLRC/` 后重启。上游明确其许可不涵盖索尼参数与 Adobe 色彩矩阵。[资源许可说明](https://github.com/751K/sony-look-bridge#license)

### 自动调整、批量曝光、直方图、目标调整与去边

- **自动白平衡／自动色调**：基本调整各提供“自动”键，基于当前裁剪区原生浮点解码估算整体中性色与六项明暗参数，可随时按 `Esc` 取消，结果作为独立起点估计。
- 在“粘贴调整”“同步调整”或“沿用上一张调整”中可分别勾选“污点修复”和“蒙版与局部调整”。位置按 EXIF 方向校正后的整张原图计算。目标照片独有的项目排在前面，传入的项目按来源顺序排列，再次同步会更新同一项目。自动选源的修复点会在目标图上重新取样，手动选源保留相对偏移。对象、人物等已识别选区只可用于原片、解码器和镜头校正一致的版本，含不匹配选区的整组蒙版会跳过，可在任务结果中查看。整批调整可撤销。
- **批量曝光**：“调整”菜单提供**应用相对曝光…**（在各照片原曝光上累加 ±⅓／±1 EV 或自定义增量，限幅 ±5 EV）与**匹配总曝光**（按活动照片的拍摄曝光参数与当前曝光计算其他照片目标曝光），均支持整批 `⌘Z` 撤销。
- **直方图拖动**：五区从左至右对应黑色、阴影、曝光、高光与白色，左右拖动或方向键微调（`Shift` 精调），松手保存一次，`Esc` 取消。
- **图上目标调整**：支持 HSL（色相／饱和度／明亮度）、黑白混色与当前曲线通道，直接从输出几何的浮点线性图取样并上下拖动调节。
- **手动去边**：独立控制紫边（200–360°）与绿边（40–200°）数量与色相范围，支持图上取样与上下拖动调量，可随通用细节同步和存入预设。
- **几何校正**：透视分组提供“画线拉直”、“引导透视”（2–4 条参考线，可点选、拖端点、按 `Delete` 删单线，`Enter` 提交、`Esc` 取消）与自动透视四种模式，保留现有裁剪与“约束裁剪”。

### 相机兼容性诊断

选择“帮助 → 相机兼容性…”可对选定目录前 32 个 RAW 候选执行只读检查（解码、重复显影、草稿／质量图、缩略图、16 位渲染与压缩比特流校验），并可保存不含照片、路径、文件名或 GPS 的本地 JSON 报告。

### 照片合成、精修与星轨

- **发起合成**：选中 2–128 张同类型原片（关闭对齐的星轨上限 2048 帧），通过“照片 → 照片合成”选择全景、HDR、HDR 全景、对焦包围、均值、稳健均值（5–128 张剔除异常像素）、中值、多重曝光、变亮／星轨、变暗或滤色。全景与 HDR 全景可选自动调平、0–100% 边界变形与扩散填边（默认关闭）。
- **暗场校准**：星轨、均值、稳健均值与中值支持标记 1–128 张同机同参暗场，在线性 RGB 中逐像素扣除热点后再融合。
- **母版保存与组织**：预览确认后保存为独立线性 sRGB 32 位浮点 TIFF 或 DNG 母版（保留超白高光与透明度，不改写来源原片；Apple RAW 解码器暂不能完整读浮点 DNG，跨软件看图可选 TIFF）。默认勾选“与来源照片堆叠”，结果置前并折叠来源，支持撤销堆叠。
- **精修合成与工程重开**：对焦、HDR、全景、HDR 全景与星轨支持在预览后点击“精修合成…”或后续通过“继续编辑合成…”重开内嵌工程，进行 1:1 来源／结果同步对照、来源保留／排除画笔、覆盖检查点与整帧排除；星轨还支持 0–16 px 断点填补、0–128 帧彗星拖尾以及无覆盖导出累计 PNG 序列（供制作延时视频）。再次保存须使用新文件名，不覆盖旧母版。

### 使用内置插件

在“设置 → 插件”启停随包插件，三个工具均从“编辑”调整面板进入：

- **软打样**：点击顶部打印机键选择输出 ICC 配置，切换送印源与模拟印刷画面并可开启目标色域警告；关闭恢复普通画布，不影响配方与普通导出。
- **选取高光**：点击顶部虚线圆键预览裁区内亮部选区，应用后生成可继续修边与撤销的原生亮度范围蒙版。
- **暖调印相**：展开同名分组拖动强度并点击“应用”（0% 移除，全尺寸上限 6000 万像素），效果随版本、撤销与导出保留；跨机继续使用请选择整库归档携带阶段文件。

## 4. 导出成片

1. 选中照片点击“导出”（或“文件 → 导出所选照片…”），选择输出文件夹、色彩空间（默认 sRGB，可选 Display P3）、格式（含透明区域的 JPEG 需选黑／白铺底，PNG 8 位与 TIFF 16 位保留透明度）、尺寸、命名与元数据策略（默认不附带源元数据）。
2. 在“检查文件”核对命名冲突后导出；目标已有同名文件永不覆盖。

## 备份与恢复已有图库

### 归档整个图库

选择“文件 → 目录维护 → 归档整个图库…”，在目标位置生成普通项目文件夹，并排保存 `.phoscat` 与同级原片文件夹（如 `旅行.phoscat` 与 `旅行.phoscat-files`，可附带额外项目资料）。所有文件核验后发布；换盘或换 Mac 时整体迁移项目文件夹，直接双击 `.phoscat` 即可继续编辑。

### 只备份图库数据库

1. 选择“文件 → 目录维护 → 备份图库…”生成独立的 `.sqlite` 备份（无覆盖，**不含原片、附件与导出文件，请另行备份原片**）。
2. 恢复时选择“从备份恢复…”，恢复为新的 `.phoscat`（不覆盖既有文件）。若原片离线或换盘，右键侧栏文件夹选择“重新授权 / 定位…”或对单张使用“照片 → 定位当前原片…”。
3. “迁出 JSON 管理清单…”仅用于查阅管理信息，不能代替 SQLite 备份；分享图库、备份或清单前请检查隐私信息。开发阶段不提供旧 schema 迁移，升级前请保留现有图库、备份与原片。
