# 上手指南

Phosdeck 目前处于开发预览阶段。第一次体验建议使用几张合成图片或有权使用的照片副本，并将照片、图库和导出文件分别放在容易辨认的位置。源码构建方法见 [README](../README.zh.md#快速上手)。

应用中的“目录”指图库数据库，保存照片位置、整理信息和调整，新建文件扩展名为 `.phoscat`。原片单独存放在照片文件夹中。

## 1. 新建图库

1. 打开 App，选择“文件 → 新建目录…”。如果已有本应用的图库，也可以选择“文件 → 打开目录…”。
2. 输入目录名称，选择保存位置，点击“创建”。App 会在所选文件夹中创建 `.phoscat` 文件；根据系统提示授权该文件夹。

打开 `.omlcat`／`.omlrcat`（包括启动时恢复最近图库）会提示使用新后缀。选择“更换后缀并打开”只在原文件夹中改为同名 `.phoscat`，核验文件内容，并更新最近图库与本机工作区偏好；照片、调整和历史不变。也可选择“保持原名打开”或“取消”。同名目标已存在、图库正在使用、存在恢复日志或校验失败时会拒绝改名，保留现有文件。

Lightroom Classic 的 `.lrcat` 与本应用格式不同，不能直接打开。App 的 XMP 导入仅转换 Lightroom 预设中受支持的部分参数。

## 2. 导入照片

1. 点击“导入…”或选择“文件 → 导入照片…”，在左侧选择照片文件夹；按需要选择是否包含子文件夹。
2. 在顶部选择导入方式：

   - **添加**：原片留在当前位置，图库记录其位置。以后需要访问照片时，原文件夹和磁盘仍须可用。
   - **复制**：选择目标文件夹，App 将选中的照片复制到该位置并导入，保留来源文件；可按需携带匹配的 XMP／ACR 附件。同名冲突按提示处理。

3. 检查中间列表中的照片和状态，确认选择后点击“导入”。“跳过已入库照片”可避免重复导入当前图库中已登记的照片。导入结束后可查看工作区的“任务结果”。

支持 JPEG、RGB 单页 TIFF、支持范围内的静态 PNG，以及部分 ARW／NEF／CR3／RAF／DNG；RAW 能否读取取决于具体文件和 macOS。HEIC、Apple DNG／ProRAW 暂未开放。复制 XMP／ACR 附件时只保留文件，不同步其中的调整。

在图库侧栏右键照片根文件夹或子文件夹，选择“查看文件夹差异…”，也可选中文件夹后使用“文件”菜单的同名操作。扫描只生成预览，默认包含子文件夹；切换此选项或点击“重新检查”会重新比较。原有“重新扫描”仍会直接索引文件。

预览按新增、缺失、变更、疑似移动和需检查分类，所有操作默认未选。新增项可按原位置添加；缺失或内容变更项可标记不可用，保留原身份、编辑、历史和虚拟副本。已恢复的原身份或与已保存摘要相同的内容可核验后恢复可用状态。疑似移动在扩展名相同的文件间，根据文件身份或已保存内容匹配；多个候选须手动选定位置，同一文件不能同时对应多个原片。

选择要处理的行，核对操作和路径后点击“应用所选差异”。确认时会重新核验文件、授权与目录记录，所选变化在一个事务中保存；发现过期结果、冲突、保存失败或在发布前取消时，整个选择均不写入。不会移动、替换或删除原片，也不会删除缺失记录。离线目录和无法完整读取的文件夹会报告错误，不据此批量标记缺失；导出成片、已登记附件、符号链接、云端占位与包内容不作为新增照片。交互参考 [Adobe 文件夹同步说明](https://helpx.adobe.com/lightroom-classic/desktop/manage-catalogs-and-files/create-folders.html)，实际行为以本指南的原生数据保护规则为准。

## 3. 整理与编辑

在图库中选择照片，可使用底部的评级、标旗和颜色标签整理。点击顶部“编辑”或按 `D`，在右侧调整曝光、白平衡等参数；`⌘Z` 可撤销支持撤销的操作。

基本调整的白平衡与明暗分组各有“自动”键。自动白平衡从当前裁剪区域的原生浮点解码估计整体中性色（已应用拍摄时白平衡和原生基准的线性 sRGB），再通过实际 RAW／Core Image 白平衡变换求出色温与色调；它采用 [Shades of Gray](https://library.imaging.org/admin/apis/public/api/ist/website/downloadArticle/cic/12/1/art00008) 的六次范数假设，排除透明、近黑与通道剪切像素。单色场景或混合光可能估计错误，请使用中性区域取样或手动参数。

自动色调在当前白平衡下分析裁剪区域的亮度分布，以中位亮度和两端分位数为目标，经现有管线求出曝光、对比度、高光、阴影、白色与黑色；自动建议的曝光限于 ±3 EV，其余参数采用保守范围。原有色彩、曲线、局部调整和几何保留，分析不受当前明暗、HSL、黑白或分级效果反馈。高调、低调照片需要人工微调。这是 Phosdeck 的原生起点估计，不能还原已丢失的细节，也不等同于 [Lightroom 的自动算法](https://helpx.adobe.com/lightroom-classic/desktop/process-and-develop-photos/image-tone-color.html)。分析中可点“取消分析”或按 Esc；换图、切工具或改参数也会丢弃结果。成功只保存一次，可用 `⌘Z` 撤销；信息不足、源文件变更或分析失败时保留原配方。

调整和整理信息保存在图库中，原片不会因编辑而被覆盖。需要分享或交付时，再导出新的成片文件。

选中需要一起调整的照片，在工作区“调整”菜单选择“应用相对曝光…”，输入曝光变化，或用 ±⅓ EV、±1 EV 按键选择增量，再点击“应用”。每张照片在自己的曝光值上累加该增量，结果限制在 −5 到 +5 EV；其他调整和基准保持不变，`⌘Z` 可撤销整个批次。这与粘贴或同步调整中覆盖曝光值的行为不同。

多选照片并将已调整的照片设为活动照片，在“调整”菜单选择“匹配总曝光”。以活动照片的光圈、快门、ISO、原生 RAW 基准曝光和当前曝光为参考，计算其他照片的曝光值；其他参数保持不变。这是拍摄参数匹配，不分析场景亮度；交互参考 [Adobe“匹配总曝光”说明](https://helpx.adobe.com/lightroom-classic/desktop/process-and-develop-photos/develop-module-options.html)。活动照片缺少有效拍摄参数时不执行；无效目标逐张跳过，限幅至 ±5 EV 的目标会在任务结果中说明。成功子集一起保存，`⌘Z` 撤销整个批次。

编辑页直方图从左到右的五区对应黑色（0–10%）、阴影（10–30%）、曝光（30–70%）、高光（70–90%）和白色（90–100%）。左右拖动调整参数，Shift 精调；松手只保存一次，Esc、失焦或换照片取消尚未提交的拖动。点击绘图区后，左右方向键选分区、上下方向键微调；辅助功能也提供各分区的增减操作。原有剪切灯与下方数值输入继续可用。分区参考 [Adobe 色调控制说明](https://helpx.adobe.com/lightroom-classic/desktop/help/tone-control-adjustment.html)，拖动响应沿用原生参数范围。

HSL 混色器先选择“色相”“饱和度”或“明亮度”，再开启“图上目标调整”；黑白混色器须先启用黑白。曲线工具按当前通道取样。在照片上点击选定目标，上下拖动或用上下方向键增减；Shift 精调，松手保存一次。Esc 先取消当前拖动，再按一次退出工具；按住空格可平移。换照片、切换工具或修改其他参数会结束目标调整，不把旧取样或草稿带到新照片。

这三类目标调整取样自浮点线性 sRGB 参考图，沿用实际显示的裁剪、透视、旋转和翻转，不取屏幕、观片底或剪切覆盖的颜色。先对参考图的 3×3 邻域按透明覆盖率求平均，再将该颜色换算为当前参数的输入。HSL 在自身处理前、曲线后取色，邻接色带按现有 HSL 平滑权重一起变化；黑白混色按 HSL／自然饱和度／饱和度之后、转灰度与分级前的原生色相选带。中性色或完全透明像素不创建颜色目标。曲线在当前通道处理前取样，将该输入处的输出上下移动；距离不足 0.1% 时复用已有点，否则新增一处控制点，最多 16 点。其他点、其他通道和显影顺序保留。这些是 Phosdeck 的原生映射规则；[Adobe 的目标调整说明](https://helpx.adobe.com/lightroom-classic/desktop/process-and-develop-photos/develop-module-tools.html)不公开精确取样阶段、权重或算法，未宣称复刻其效果。

“手动去边”分组分别控制紫边和绿边，适用于 RAW、JPEG、TIFF 和 PNG；它处理解码后的残留色边，与系统 RAW 镜头校正开关分开。数量为 0–100，0 精确旁路；色相采用原生 sRGB 度数，紫边范围 200–360°，绿边范围 40–200°，两端至少相隔 10°。也可随“通用细节”复制、同步和存入原生预设；Lightroom XMP 去边参数尚不在导入范围内。

开启“取样紫边”或“取样绿边”，点击相应颜色可选定以取样色相为中心的 30° 范围；数量为 0 时从原生建议值 25 起步，已有非零数量保留。上下拖动可继续改数量，松手只保存一次；松手前按 Esc、失焦、换图或切工具取消本次草稿，之后仍可用方向键微调。取样使用当前白平衡、曝光、修复和降噪之后，手动去边、色调、曲线与 HSL 之前的浮点图。沿实际输出几何取当前像素，紧裁剪先保留原生解码，再将最终参考图限制到 2048 像素长边，不从屏幕取色。

原生去边检测中性边缘附近的局部色度异常，最多检查 12 个原图像素的邻域，保留线性亮度和透明覆盖率；平坦紫绿区域不作整体去饱和。真实紫绿细物体的边缘仍可能受影响，较宽色边也可能残留，请缩小色相范围并以 100% 检查。交互参考 [Adobe 去边说明](https://helpx.adobe.com/lightroom-classic/desktop/process-and-develop-photos/retouch-photos.html)，数量、色相单位、建议值和处理算法均为原生定义，不与 Adobe 参数作数值对应。

在裁剪工具的透视分组中，“画线拉直”沿一条应为水平或垂直的边绘制；“引导透视”绘制两至四条参考线，从第二条起求解校正。点击参考线可选中，拖动端点微调，Delete 删除选中的单条线；少于两条透视线时保留参考线并恢复本次操作前的几何参数。Enter 或“完成”提交并结束参考线；Esc 取消尚未提交的端点拖动并退出，保留已保存的校正。参考线仅用于当前操作，保存的是求出的参数；撤销或改变几何后重新绘制。自动校正提供自动、水平、垂直与完整四种方式，线条不足时保留当前编辑。当前裁剪不会被清空，“约束裁剪”继续控制空白边缘。

“帮助 → 相机兼容性…”可选择样片文件夹，顺序检查该文件夹内前 32 个 RAW 候选文件，不递归或写入图库。顶部摘要显示检查进度、可解码与异常数量，左侧选择样片，右侧查看并排预览和检查明细。检查中可停止并保留已完成的结果；“未核验”与失败、需关注分别标示。结果包括完整解码、重复显影、草稿后质量图、缩略图和 16 位渲染；可读取的内嵌预览仅供查看。保存本地 JSON 报告会记录应用、macOS、RAW 解码器和管线版本及检查结果，不包含照片、源路径、文件名、GPS 或序列号；报告包含来源摘要，可用于辨认同一份样片。尚未核验的压缩方式、传感器位深和黑白电平明确保留为未知或跳过。诊断结果不自动扩大支持范围，Apple DNG／ProRAW 的现有限制仍适用。

## 4. 导出成片

1. 选中需要导出的照片，点击“导出”或选择“文件 → 导出所选照片…”。
2. 在“导出位置”选择文件夹，在“文件设置”选择 JPEG、PNG 8 位或 TIFF 16 位及所需尺寸。JPEG 需要选择黑色或白色铺底，用于透明区域和几何变换形成的空白。
3. 在“文件命名”和“检查文件”中确认名称；目标已有同名文件时，修改名称或更换目标，导出不会覆盖它。检查“元数据”选项后点击“导出”，再查看工作区的任务结果。

输出使用 sRGB。新安装时默认不附带源元数据；App 可能记住上次的导出设置，分享前请检查当前选项。PNG／TIFF 保留透明度，JPEG 使用所选铺底。

## 备份与恢复已有图库

1. 使用“文件 → 目录维护 → 备份图库…”，选择一个新的文件名和保存位置，等待“图库备份完成 · 不含原片”。生成的是 SQLite 备份，默认扩展名为 `.sqlite`；已有同名目标不会被覆盖。
2. **另外备份原片、需要保留的附件和导出文件。** 图库备份包含图库数据库，不包含这些外部文件；编辑历史或快照也不是原片备份。建议将备份放在独立位置，并定期验证。
3. 需要恢复时，选择“文件 → 目录维护 → 从备份恢复…”，选中 `.sqlite` 备份，再为“恢复为新目录”选择名称和保存位置。恢复会创建并打开新的 `.phoscat`，不会覆盖现有同名文件；保留原图库和备份，确认新目录中的照片及调整后再决定后续操作。

恢复只还原图库数据库，不会把原片或导出文件从备份中找回。照片不可用时，先确认原片所在磁盘已连接；如需重新授权或更换根文件夹，在图库左侧的对应文件夹上右键选择“重新授权 / 定位…”，并保持其内部相对路径。单张原片可在选中照片后使用“照片 → 定位当前原片…”。App 会检查候选文件身份；未能确认的照片仍需单独处理。

“迁出 JSON 管理清单…”用于查看或迁出管理信息，**不能代替 SQLite 图库备份**。图库文件、备份和清单可能包含文件名、路径、题注及其他个人信息，分享前应检查；遇到问题时请参照[贡献与反馈指南](../CONTRIBUTING.zh.md#反馈问题)。

更换后缀不转换数据库格式。开发阶段不提供旧 schema 或旧备份的格式迁移，新版本可能拒绝旧文件。升级前请保留现有图库、备份及原片，不要为了打开新版本而删除或覆盖它们。
