# 上手指南

Phosdeck 目前处于开发预览阶段。第一次体验建议使用几张合成图片或有权使用的照片副本，并将照片、图库和导出文件分别放在容易辨认的位置。源码构建方法见 [README](../README.zh.md#快速上手)。

应用中的“目录”指图库数据库，保存照片位置、整理信息和调整，新建文件扩展名为 `.phoscat`。原片单独存放在照片文件夹中。

## 1. 新建图库

1. 打开 App，选择“文件 → 新建目录…”。如果已有本应用的图库，也可以选择“文件 → 打开目录…”。
2. 输入目录名称，选择保存位置，点击“创建”。App 会在所选文件夹中创建 `.phoscat` 文件；根据系统提示授权该文件夹。

打开 `.omlcat`／`.omlrcat`（包括启动时恢复最近图库）会提示使用新后缀。选择“更换后缀并打开”只在原文件夹中改为同名 `.phoscat`，核验文件内容，并更新最近图库与本机工作区偏好；照片、调整和历史不变。也可选择“保持原名打开”或“取消”。同名目标已存在、图库正在使用、存在恢复日志或校验失败时会拒绝改名，保留现有文件。

Lightroom Classic 的 `.lrcat` 与本应用格式不同，不能直接打开。App 的 XMP 导入仅转换 Lightroom 预设中受支持的部分参数。

## 2. 导入照片

1. 点击“导入…”或选择“文件 → 导入照片…”，在左侧选择照片文件夹；按需要选择是否包含子文件夹。
2. 在顶部选择导入方式：

   - **添加**：原片留在当前位置，图库记录其位置。以后需要访问照片时，原文件夹和磁盘仍须可用。
   - **复制**：选择目标文件夹，App 将选中的照片复制到该位置并导入，保留来源文件；可按需携带匹配的 XMP／ACR 附件。同名冲突按提示处理。

3. 检查中间列表中的照片和状态，确认选择后点击“导入”。“跳过已入库照片”可避免重复导入当前图库中已登记的照片。导入结束后可查看工作区的“任务结果”。

支持 JPEG、RGB 单页 TIFF、支持范围内的静态 PNG，以及部分 ARW／NEF／CR3／RAF／DNG；RAW 能否读取取决于具体文件和 macOS。HEIC、Apple DNG／ProRAW 暂未开放。复制 XMP／ACR 附件时只保留文件，不同步其中的调整。

## 3. 整理与编辑

在图库中选择照片，可使用底部的评级、标旗和颜色标签整理。点击顶部“编辑”或按 `D`，在右侧调整曝光、白平衡等参数；`⌘Z` 可撤销支持撤销的操作。

调整和整理信息保存在图库中，原片不会因编辑而被覆盖。需要分享或交付时，再导出新的成片文件。

## 4. 导出成片

1. 选中需要导出的照片，点击“导出”或选择“文件 → 导出所选照片…”。
2. 在“导出位置”选择文件夹，在“文件设置”选择 JPEG、PNG 8 位或 TIFF 16 位及所需尺寸。JPEG 需要选择黑色或白色铺底，用于透明区域和几何变换形成的空白。
3. 在“文件命名”和“检查文件”中确认名称；目标已有同名文件时，修改名称或更换目标，导出不会覆盖它。检查“元数据”选项后点击“导出”，再查看工作区的任务结果。

输出使用 sRGB。新安装时默认不附带源元数据；App 可能记住上次的导出设置，分享前请检查当前选项。PNG／TIFF 保留透明度，JPEG 使用所选铺底。

## 备份与恢复已有图库

1. 使用“文件 → 目录维护 → 备份图库…”，选择一个新的文件名和保存位置，等待“图库备份完成 · 不含原片”。生成的是 SQLite 备份，默认扩展名为 `.sqlite`；已有同名目标不会被覆盖。
2. **另外备份原片、需要保留的附件和导出文件。** 图库备份包含图库数据库，不包含这些外部文件；编辑历史或快照也不是原片备份。建议将备份放在独立位置，并定期验证。
3. 需要恢复时，选择“文件 → 目录维护 → 从备份恢复…”，选中 `.sqlite` 备份，再为“恢复为新目录”选择名称和保存位置。恢复会创建并打开新的 `.phoscat`，不会覆盖现有同名文件；保留原图库和备份，确认新目录中的照片及调整后再决定后续操作。

恢复只还原图库数据库，不会把原片或导出文件从备份中找回。照片不可用时，先确认原片所在磁盘已连接；如需重新授权或更换根文件夹，在图库左侧的对应文件夹上右键选择“重新授权 / 定位…”，并保持其内部相对路径。单张原片可在选中照片后使用“照片 → 定位当前原片…”。App 会检查候选文件身份；未能确认的照片仍需单独处理。

“迁出 JSON 管理清单…”用于查看或迁出管理信息，**不能代替 SQLite 图库备份**。图库文件、备份和清单可能包含文件名、路径、题注及其他个人信息，分享前应检查；遇到问题时请参照[贡献与反馈指南](../CONTRIBUTING.zh.md#反馈问题)。

更换后缀不转换数据库格式。开发阶段不提供旧 schema 或旧备份的格式迁移，新版本可能拒绝旧文件。升级前请保留现有图库、备份及原片，不要为了打开新版本而删除或覆盖它们。
