SQLite catalog dependency notices (M3)

SQLite 3.53.2 is bundled statically via libsqlite3-sys 0.38.2.
rusqlite and the native additions below are used under MIT. vcpkg is a build-time tool.
Sources are pinned in engine/Cargo.lock; crates are available at https://crates.io/.
The wasm-only sqlite-wasm-rs and rsqlite-vfs lock entries are not compiled or shipped in desktop builds.
This file covers this batch of additions, not the existing full-distribution license audit.
