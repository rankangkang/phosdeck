Phosdeck's ACROS, ACROS + Ye, ACROS + R, ACROS + G, REALA ACE and Sepia
resources use the independent simulations in Fuji Recipe Converter.

scripts/pack-camera-looks.py runs FR.derive and FR.buildLut from js/data.js
and js/engine.js with the default recipe settings for each film simulation.
The display-referred sRGB transform follows FR.toCube in js/export.js. The
script resamples it to Phosdeck's extended-linear-sRGB grid with highlight
headroom. Only the generated look tables are included in the app.
