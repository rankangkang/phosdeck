# 工程手册：性能调优与本地构建体验

高频交互性能准则与固定体验 App 构建签名约定。日常红线与入口见 [AGENTS.md](../AGENTS.md)，架构边界与测试映射见 [架构地图](architecture.md)。

## 高频交互与性能

### 1. 视图观察与布局边界

- 滑块、画布与实时预览的状态由最小消费视图读取，避免工作区根视图订阅局部高频变化；拆分 View 后仍须核查实际观察范围。
- 复用视图时覆盖模型身份和交互行为；折叠面板按展开状态构造内容。
- 画布与侧栏保持明确的布局边界，避免像素或状态文本更新带动无关区域反复测量。

### 2. 主线程调用链与并发隔离

- 检查完整主线程调用链，包括参数校验、JSON 编解码、摘要计算、数据库访问与显示资源获取。
- 高频路径避免重复的大载荷处理和同步等待 GPU／drawable；后台工作只传递不可变快照，原生视图访问与状态发布严格遵守 `MainActor`。
- `Task {}` 不保证离开 `MainActor`；调整线程安排时仍须保留保存成功、错误报告与撤销语义。

### 3. 缓存身份与增量刷新

- 未变的数据复用派生结果，局部编辑只刷新受影响照片与新增历史。
- 缓存键与等价比较覆盖所有影响结果的维度：来源身份、尺寸、参数及渲染模式；保留损坏数据、来源身份与尺寸校验。
- 增量查询与物化索引必须保留既有排序、分页、换照片及撤销／重做行为。

### 4. 有界预览调度

- 预览请求保持有界，合并为最新待处理状态，提交时核对照片、配方版本与会话；相同最终草稿可复用。
- 引入节流或防抖时须说明目的及端到端延迟代价，不能靠不断增开并发任务追赶过时输入。

### 5. 基线测量与回归纪律

- 性能优化先采集基线，分段区分：输入／校验保存、预览请求、后台计算、主线程发布、画布更新与显示提交。
- 前后对照固定样片、蒙版、参数、窗口、显示器、预览尺寸和构建配置，记录自动化／采样开销；保留逐次数据、中位数、最大值及异常。
- 条件不同时不宣称严格提升比例；publish／呈现回调不冒充物理屏幕延迟。
- 为实际修复的阻塞、积压／过期结果、缓存身份和增量状态边界补最小回归；受控测试验证隔离与正确性，实窗测量验证端到端体验。
- 候选机制标为假设，注入阻塞不等于原异常复现，常规样本变快不代表偶发卡顿已解决；工程检查通过不替代用户验收。
- 测量原始数据放在已忽略的 `build/` 下，结论与关键数字写进提交说明；仍未解决的问题记入 [STATUS.md](STATUS.md)。

## 原生 App 构建与体验

### 1. 常驻体验目录与样本边界

- 交给用户体验的图库、样片和需要保留的体验结果统一放在本机 `~/Phosdeck Review/`：
  - 日常浏览与选片：`Public Review.phoscat` 与 `Public Photos/`（已准备公开图库的机器）。
  - 合成大图库压测：`Review.phoscat` 与 `Photos/`。
- 构建产物、自动测试和测量原始数据使用 `build/` 或测试临时目录。
- 自动测试只使用合成数据、`Samples/public-cc0/` 或已授权只读的 `Samples/PublicRAW/`，不得自动打开正式产物身份可能恢复的私人最近目录。

### 2. 固定体验 App 与更新流程

- 固定体验 App 路径：`build/unrated-stars-review/Phosdeck Preview.app`
- 固定 bundle ID：`dev.cmkk.oh-my-lrc.unratedstars20261021`
- 普通开发与流程审查固定复用同一份体验 App，使用 `./scripts/update-preview.sh` 更新：
  1. 正常退出正在运行的体验 App；
  2. 执行标准 Xcode Debug 增量构建（产物位于 `build/Build/Products/Debug/Phosdeck.app`）；
  3. 设置体验包名称、bundle ID 与配套插件绑定，按已安装体验包的开发证书由内向外重新签名并核验，再用 `RENAME_SWAP` 原子替换；
  4. 保留原有图库、原片、偏好以及沙箱、hardened runtime 与各组件 entitlements。
- 更新后打开同一路径及所需的体验图库。若旧环境仍保留早期文件名 `oh my lrc Star Review.app`，先正常退出并核对目标无冲突，再同目录无覆盖更名并使用原开发身份重签，不替换图库和偏好。

### 3. 构建与签名禁忌

- 标准 Debug 增量构建命令：

```sh
xcodebuild -project Phosdeck.xcodeproj -scheme Phosdeck -configuration Debug -derivedDataPath build -destination 'platform=macOS' build
```

- **禁止**通过全局 `PRODUCT_NAME`／`CONFIGURATION_BUILD_DIR` 重定向所有依赖目标（会破坏 GRDB 资源包名称）。
- **禁止**为普通体验切换主工程的 bundle ID。
- 本机有开发证书且已选择稳定签名时，通过已忽略的 `Config/LocalSigning.xcconfig` 固定证书和团队。测试宿主、XCTest 包、Debug／预览及嵌套动态库（如 LiteRT）使用同一身份；暂存或去除调试映射后由内向外重签，保留各自 entitlements 与 hardened runtime，不得用 `--sign -` 覆盖稳定身份。无开发证书的机器继续沿用默认免证书构建。
- 复用 `build/` 增量缓存；清理历史结果或副本前须单独核对归属，不能把整个 `build/`、用户目录或照片当作可随意删除的缓存。
