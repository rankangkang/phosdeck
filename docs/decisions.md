# 已定决策

长期决定及重新考虑的条件。当前进展见 [STATUS](STATUS.md)。

## 不做

| 决定 | 原因 | 重新考虑 |
|---|---|---|
| 水印 | 用户决定 | 用户重新提出 |
| 完整 XMP 元数据交换（sidecar 读写与双向同步） | 用户决定；XMP 仅做 Lightroom 预设子集只读导入，不支持 ZIP／目录／lrtemplate／内嵌预设 | 用户重新提出 |
| 自有预设包导入／导出 | 用户决定 | 用户重新提出 |
| 专用持久恢复区 | 调查未发现 Classic 中的可靠对应功能 | 有具体误删恢复需求 |

## 暂缓

| 决定 | 原因 | 重新考虑 |
|---|---|---|
| 集合组 | 需真实多项目需求，且涉及 schema | 出现真实多项目需求 |
| 输出锐化、广色域输出 | 缺摄影证据 | 有摄影证据或用户恢复 |

| 其余性能优化（含标准预览前置） | 已按用户指令完成合成匹配、Agent 局部／整图预览与图库小缩略图优化，其余暂缓 | 用户明确恢复其他范围 |

| 命令搜索、工作区预设、自适应局部预设、新增蒙版边缘精修 | 用户明确当前不在范围，优先几何校正与相机兼容性 | 用户重新提出 |

## 界面与交互

| 决定 | 原因 | 重新考虑 |
|---|---|---|
| 控件内焦点提示（不用系统蓝色外环） | 避免外框干扰观片，同时保留键盘导航与辅助功能 | 焦点识别不足时 |
| 未调整 RAF 首次浏览先用机内 JPEG，停留适窗切回原生显影 | 提升选片速度；已编辑版本始终用保存配方 | 要求浏览始终匹配显影色时 |
| 相机风格走原生显影与版本化色表，“按拍摄风格”用同帧机内 JPEG 校准 | 预览、重开与导出可按同一配方复算；首批采用许可明确的开源近似色表 | 使用范围或切换语义变化时 |
| 插件首批内置三工具（软打样／选取高光／暖调印相），先验证跨团队公证包再开放第三方 | 各验证一种接入口，降低第三方开放风险（见 [插件系统方案](plugin-system.md)） | 接入口或分发方向变化时 |
| Agent 通过本地 MCP（Streamable HTTP `2025-11-25` + Swift SDK + SwiftNIO）与随包 Skill 覆盖完整工作流 | 用户明确要求全流程 Agent 化；系统分配端口支持正式版与 Preview 并行 | 覆盖范围、协议或互通变化时 |
| Agent 独立查图不改原生视图；辅助选片基于原片缩略图；逐张调整按显式版本整批原子提交 | 保持用户工作区稳定，防止局部失败导致半提交；连续堆叠比较留在原生工作区 | 工作区联动或批处理语义调整时 |
| 图库分格陈列：纯色直角屏边、共享细分隔线、去扩展名名称与独立类型左右分列、悬停中性变底、悬浮滚动条与胶片带滚轮横滚 | 用户要求简洁连贯机身面、信息在图像之外并简化陈列 | 重新决定网格外观或交互时 |
| 展开堆叠限定当前来源与筛选，完整匹配简写总数，不完整显示 `匹配/整组` 并提示未显组员 | 保留查询边界并保持入口紧凑 | 要求跨范围展示时 |
| 多帧合成、收边、精修与 DNG32 沿用原生界面与线性 sRGB 浮点管线，默认与来源堆叠 | 保持有符号像素、高光与透明度语义，吸收 Lightroom 合成组织方式 | 技术或组织方式调整时 |
| 编辑工作区沿用暗房仪表外观（琴键＋推子）、直方图剪切合并为两颗灯键、换图暂锁控件并用底栏指示加载、禁用控件保留实体触感 | 用户确认视觉与机械反馈方向，减少说明文字 | 重新决定视觉或交互方向时 |
| 几何校正保留 `camera-rotation-v2` 与既有坐标，仅移植 MPL-2.0 直线检测并参考 Lightroom 公开交互 | 不破坏已有蒙版、修复与输出语义 | 更换几何模型时 |
| 相机兼容性诊断按本地实证记录，不上传报告、未知模式不推定通过 | 避免误判支持范围，先完成当前版本验收 | 取得新公开样片或扩大范围时 |
| 照片工作区中文称“编辑”、英文称 Develop（保留 `D` 快捷键） | 中文直观，英文沿用行业术语 | 用户重新决定时 |

## 数据与图库

- 固定合成图库的现有数据全部保留，验证历史照实保留，不回灌旧备份或为字节一致覆盖图库。
- 图库统一 `.phoscat` 后缀；旧 `.omlcat`／`.omlrcat` 打开时允许确认原位置无覆盖改后缀，不改内部数据，不做旧 schema 迁移。
- `.phoscat` 支持单选、访达与最近目录打开；关联文件机制授权锁／日志／归档原片目录，`Files` 布局与旧后缀改名按需申请目录授权。
- 整库归档为普通项目文件夹，并排保存 `.phoscat` 与 `.phoscat-files` 原片目录，保留相对路径与完整项目资料，换机双击 `.phoscat` 即开。
- 改 schema 若涉及更新固定合成图库须用户再次许可；缺少当前冻结快照字段的旧输出任务拒绝重试并保留原记录与成片。
- 模型权重、自动测试样片与测量输出放已忽略的 `build/`，用户体验数据按 [常驻体验目录约定](engineering.md#1-常驻体验目录与样本边界) 保留。
