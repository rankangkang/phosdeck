# 已定决策

长期决定及重新考虑的条件。当前进展见 [STATUS](STATUS.md)。

## 不做

| 决定 | 原因 | 重新考虑 |
|---|---|---|
| 水印 | 用户决定 | 用户重新提出 |
| 完整 XMP 元数据交换（标题／作者／版权、sidecar 读写与双向同步） | 用户决定；XMP 只做 Lightroom 预设子集只读导入，不支持 ZIP、目录、lrtemplate 与照片内嵌预设 | 用户重新提出 |
| 自有预设包导入／导出 | 用户决定 | 用户重新提出 |
| 专用持久恢复区 | 调查未发现 Classic 中的可靠对应功能 | 有具体误删恢复需求 |
| 含原片的图库备份 | LRC 目录备份同样不含原片与导出 | 有具体需求 |

## 暂缓

| 决定 | 原因 | 重新考虑 |
|---|---|---|
| 集合组 | 需真实多项目需求，且涉及 schema | 出现真实多项目需求 |
| 输出锐化；广色域／软打样（色域警告随之一起做） | 缺摄影证据 | 有摄影证据或用户恢复 |

| 命令搜索、工作区预设、自适应局部预设、胶片模拟与新增蒙版边缘精修 | 用户明确当前不在范围，选定几何校正和相机兼容性 | 用户重新提出 |

## 界面与交互

- 图库相邻格共用一条分隔线，列表序号不补前导零；名称去扩展名后与独立类型左右排列，组织状态保留底栏。堆叠入口参考 Lightroom 的小数字与边缘把手，名称／类型参考 Lightcraft，使用原生控件并保持信息在图像之外；用户要求简化陈列并分开显示名称与类型，重新决定网格外观时调整。
- 展开堆叠继续限定当前来源与筛选，范围不完整时显示匹配数／整组数并明确提示未显示的组员，完整匹配时数量简写为总数；用户选择保留查询边界并要求紧凑入口，用户要求跨范围展示时重新考虑。
- 照片合成提供可选的来源堆叠，结果置前、来源可展开；复用原生堆叠和撤销，旧组仅移出参与版本，保留其他成员；用户确认吸收 Lightroom Classic 的合成组织方式，不改变浮点像素管线，用户重新决定组织方式时调整。
- 多帧合成及可选自动调平、边界变形、填充和 DNG 输出沿用现有原生 SwiftUI 界面与线性 sRGB 浮点管线；用户明确要求，保持有符号像素、高光与透明覆盖率，不套用上游相机 RGB 元数据，用户改变技术或功能方向时重新考虑。
- 直方图暗部与高光剪切各复用一颗基础文字灯键，去掉眼睛图标及外置可点击文字；未开启且未按住时灯灭，开启覆盖或按住时灯亮，由基础按键样式统一处理，用户要求合并入口并复用设计组件，重新决定交互时调整。
- 换照片时编辑侧栏保留现有控件与外观，载入期间暂锁编辑，反馈集中在固定状态位；用户要求避免控件消失及整片反复变灰，真实不可用项仍保留禁用样式，重新考虑需用户确认。
- 禁用控件保留实体外观，受力反馈遵循各自机械特性：按键向下触底，推子沿轨道短行程受阻、松手归位；用户要求不同控件不套用同一动作，用户重新决定物理表现时调整。
- 编辑区域沿用用户确认的 stageshow 外观方案，以原生 SwiftUI 琴键与水平推子落实分组、数值对齐及独立照片信息条；保留全部操作、快捷键、中性观片底和显影管线，不移植演示用 React／CSS 或示意数据；用户重新决定视觉方向时调整。
- 几何校正保留 `camera-rotation-v2`、现有裁剪和图像坐标；Lightroom 只参考公开交互，Redlamp 只移植已注明 MPL-2.0 来源的直线检测，求解器适配原生参数；避免改变既有蒙版、修复及输出语义；更换几何模型时重新评估。
- 当前相机兼容性诊断功能与界面按用户决定先通过验收；兼容性仍按实际文件、macOS、解码器和管线版本记录本地证据，内嵌预览仅供异常排查，未知模式不推定通过，不上传报告；取得新的公开样片或用户决定扩大范围时重新评估。
- 照片工作区中文称“编辑”、英文称 Develop，保留 D 快捷键；中文更直观，英文沿用摄影工作流术语；用户重新决定时调整。

## 数据与图库

- 固定合成图库的现有数据全部保留（含用户自建蒙版组、调整、历史、输出记录）；验证产生的历史照实保留，不回灌旧备份，不为字节一致覆盖图库。
- 图库后缀统一为 `.phoscat`；用户要求旧 `.omlcat`／`.omlrcat` 继续可打开，并在打开时确认是否在原位置无覆盖改名。只改后缀、不改内部数据；不迁移旧 schema，用户重新决定时再考虑。
- 改 schema 时如需更新固定合成图库，须用户再次明确许可；此前的单库例外不可复用，正式 App 仍不加 schema 迁移。
- 缺少当前冻结快照字段的旧输出任务拒绝重试，其数据与成片原样保留。
- 模型权重、公开样片及对照生成的原始图像和输出放在已忽略的 `build/` 下；不含私人信息的合成图对照记录、校准工具和回归测试保留在仓库。
