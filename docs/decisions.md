# 已定决策

长期决定及重新考虑的条件。当前进展见 [STATUS](STATUS.md)。

## 不做

| 决定 | 原因 | 重新考虑 |
|---|---|---|
| 水印 | 用户决定 | 用户重新提出 |
| 完整 XMP 元数据交换（标题／作者／版权、sidecar 读写与双向同步） | 用户决定；XMP 只做 Lightroom 预设子集只读导入，不支持 ZIP、目录、lrtemplate 与照片内嵌预设 | 用户重新提出 |
| 自有预设包导入／导出 | 用户决定 | 用户重新提出 |
| 专用持久恢复区 | 调查未发现 Classic 中的可靠对应功能 | 有具体误删恢复需求 |
| 含原片的图库备份 | LRC 目录备份同样不含原片与导出 | 有具体需求 |

## 暂缓

| 决定 | 原因 | 重新考虑 |
|---|---|---|
| 集合组 | 需真实多项目需求，且涉及 schema | 出现真实多项目需求 |
| 相对批量曝光 | LRC 实测未得到可核验的变化 | 补测得到可核验行为 |
| 输出锐化；广色域／软打样（色域警告随之一起做） | 缺摄影证据 | 有摄影证据或用户恢复 |
| 快照“用当前设置更新”、快照创建／改名撤销 | 未纳入已交付批次 | 用户恢复 |
| 档位旋钮其他接入位置与拖动吸附 | 用户决定暂缓 | 用户恢复 |
| 原生 CI | 用户决定暂缓 | 用户决定恢复 |
| 性能优化、JPEG 差异调查、Lightroom 对照 | 用户要求告一段落 | 用户明确恢复 |

## 公开维护

| 决定 | 原因 | 重新考虑 |
|---|---|---|
| 项目与应用统一命名为 Phosdeck | 用户选定；贴合暗房仪器工作台风格 | 用户重新决定名称 |
| README 和贡献指南的英文版使用 `README.md`、`CONTRIBUTING.md`，中文版使用 `README.zh.md`、`CONTRIBUTING.zh.md`；各版本互相链接 | 用户要求，方便两种语言的读者使用和参与 | 用户重新决定文档语言安排 |
| Phosdeck 字标使用现有圆角 SVG 字形与加粗的 e 横笔画，保留 o 的橙点与缺口、石墨和米白主题色，应用图标造型不变 | 用户选定；固定 SVG 保留字形 | 用户重新决定字标 |
| 本仓库固定使用日常提交身份 | 用户要求，避免继承工作邮箱 | 用户更换公开身份 |
| 公开说明 Lightroom 的功能与工作流参考，以及开源项目的移植与适配 | 用户要求如实致谢，按实际使用范围保留归属 | 参考或复用范围变化 |
| 保留普通图像曝光响应表、对照记录、校准工具与回归测试 | 用户确认；公开说明合成图对照来源，使用依据仍待核对 | 核对结果要求调整或用户决定替换 |

- UI 与品牌以石墨深色为主：首次使用默认石墨，保留已有主题选择；应用图标在系统浅色与深色外观下均使用石墨底、橙色灯点，沿用灯环及刻度造型。用户重新决定主色调时再调整。

## 数据与图库

- 固定合成图库的现有数据全部保留（含用户自建蒙版组、调整、历史、输出记录）；验证产生的历史照实保留，不回灌旧备份，不为字节一致覆盖图库。
- 图库后缀统一为 `.phoscat`；用户要求旧 `.omlcat`／`.omlrcat` 继续可打开，并在打开时确认是否在原位置无覆盖改名。只改后缀、不改内部数据；不迁移旧 schema，用户重新决定时再考虑。
- 改 schema 时如需更新固定合成图库，须用户再次明确许可；此前的单库例外不可复用，正式 App 仍不加 schema 迁移。
- 缺少当前冻结快照字段的旧输出任务拒绝重试，其数据与成片原样保留。
- 模型权重、公开样片及对照生成的原始图像和输出放在已忽略的 `build/` 下；不含私人信息的合成图对照记录、校准工具和回归测试保留在仓库。
