## 材质与几何

光源统一在上方。凸起件上亮下暗、投影向下；凹入件保留上边内影与下边亮边。机身不加噪声、照片纹理、玻璃反射或装饰光晕。轻微厚度来自底侧面和投影，不在操作件周围增加外框或空白键槽。

| 部位 | 几何与光影 |
|---|---|
| 普通键 | 28 pt 高、3 pt 外圆角；顶面不内缩，底侧面 1.25 pt；顶沿高光 0.5 pt，接触影 y 0.8／radius 0.6，扩散影 y 2／radius 2.5 |
| 紧凑键 | 18／22／24 pt 高；小于 22 pt 的底侧面 0.75 pt；联排键只在整组外角倒圆，保留 1 pt 接缝 |
| 选中与按住 | 锁定时底侧面缩至 1/4，按住时为 0；选中用中性面、加粗字与橙灯；减少动态效果时取消标签位移和选择动画 |
| 禁用按键 | 保留键帽渐变、侧壁与锁定位置；键面叠加 45% `surface.panel`，高光随键面减弱，阴影为原不透明度的 45%。文字／图标用 `text.disabled`，轮廓 0.5 pt 材质暗边，增大对比度时用 1 pt `border.control`。鼠标受压只走剩余行程的 40%，松开、拖出或失焦回弹；语义仍为禁用，不响应悬停。禁用橙色主键改用同高度中性实体键 |
| 橙色主键 | 树脂渐变，相同薄底侧面与短投影；不加内缩的整圈白色高光 |
| 档位旋钮 | 底座 44 pt、帽面 34 pt，同心，四边等距内缩 5 pt。引线先沿档位径向伸出再折向横／竖尾段，端点与文字对齐，折角圆接；当前引线 1.5 pt、其余 1 pt，当前文字加粗，指针为信号橙。不画系统焦点外框，保留点击、方向键及辅助功能选择器 |
| 水平推子 | 槽高 3 pt，帽面 9×16 pt，保留侧壁、顶面高光和中线；交互区域仍为 28 pt 高并带数值输入。聚焦或拖动时只改变帽面中线，不画彩色外框；导入和图库的缩略图大小复用此推子 |
| 禁用推子 | 保留凹槽、实体帽面渐变、侧壁和阴影；帽面与彩色轨道叠加 45% `surface.panel`，阴影降为 45%，刻度与中线用 `text.disabled`，沿用材质暗边。抓住帽面沿轨道最多移动 ±2 pt 后硬止挡，受轨道端点限制；松手以 120 ms 回位动画释放，失焦、移除控件或恢复可编辑立即归位，减少动态效果时取消回位动画。反馈只改变帽面的显示位置，不改变数值、不提交历史，键盘与辅助功能保持禁用 |
| 横向拨片 | 58×26 pt，帽面 25×20、行程 27；只在右侧显示“已开启／已关闭”，橙色只表示开启。高光沿轮廓内缩 1 pt 并裁切。26×50 pt 上下拨杆（20 pt 圆球、居中指示点、圆弧杆端、无附加椭圆阴影）保留为组件，当前表单不使用 |
| 数据屏与机身 | 连续机身、细分组线、数据屏外 3 pt 斜面；照片、观片底、缩略图和 Metal 预览不参与材质绘制 |

界面以石墨深色为主，首次使用默认石墨；已有主题选择保持不变，仍可选择米白或跟随系统。石墨与米白使用相同几何。材质轮廓用 `material.edge`；状态识别靠键盘焦点、选中灯、文字和增大对比度下的边界。禁用反馈遵循各控件的运动方向与机械约束：按键向下触底，推子沿轨道限位，不统一套用按压位移。

键面带灯键统一由 `KeyButtonStyle`（`.key(lampInside: true)`）组合键帽与 `LampLabel`，灯随选中或可用按压点亮，禁用受压不点亮。`KeyRow` 的键面灯与独立带灯键复用此样式；业务视图只提供状态和操作，不另绘灯位或计算按压亮灭。

## 连续参数与布局

- 曝光、对比度及其他连续数值一律用“标签／水平推子／数值”逐行布局；旋钮只用于观片底等低频离散档位。
- 数值列固定预留 16 pt 单位位置，无单位时仍保留；数值输入框保持同宽、右边缘对齐。基本调整按“白平衡／明暗／质感与色彩”分组，白平衡模式沿参数控制列对齐，不重复显示标题。
- 推子向右增大，抓住帽面不跳值；Shift 为 1/10 精调，切换 Shift 时重建锚点，一次拖动只提交一次。方向键、无障碍增减、双击复位、数值输入和撤销保持接通；滚轮经过只滚动面板。
- 数值输入在提交或失焦时校验；非数字、非有限值及超出范围的草稿保留原文，在字段下方用错误图标、错误色和文字说明允许范围及 Esc 取消方式，并发送辅助功能播报。有效纠正才改值，取消、原值提交及切换照片不产生修改。
- 检查布局时覆盖 1440×900、1280×800、1000×640，两种照片方向与两种主题。照片坐标、观片底颜色、配方、取样与导出不随材质变化。

## 表单与开关

| 操作关系 | 原生形式 |
|---|---|
| 固定、少量互斥选项 | 联动琴键（导出元数据、主题、自动堆叠范围、智能集合布尔值等）；短表单键的状态灯放在键面 |
| 独立多选 | 自锁键（照片勾选、候选来源、配对确认、批量调整项目）；多行标签可增高，导入缩略图文件名单行 |
| 命名组成 | 拍摄日期、原文件名、连续序号各自锁定，上方显示首张照片的真实值，固定顺序；预览与列表都用 `ExportNamingPlanner` 结果 |
| 视图行为开关 | 显示选区、点颜色影响范围、约束裁剪、比较同步缩放用横向拨片 |
| 导入／导出行为开关 | 横向拨片，标题在左，开关与单一状态文字在右对齐；长标题只在左列换行。附件选项只在复制模式出现；“限制长边”同样用拨片 |
| 有顺序的固定档位 | 缓存额度 1／5／10 GiB 滑槽，三档吸附，双击回默认 5 GiB |
| 有界整数 | 数值窗加相邻加减键，支持直接输入、Enter 提交、Esc 取消和相邻错误提示；无效草稿保留最后有效值，并阻止保存预设与导出入队 |

动态或标签较长的选项（预设、来源、集合等）用原生菜单。处理方式、暗角样式、智能选区方式、HSL 与色轮视图保留直接琴键入口，空间不足时完整保留标签并换行；每行只在外角倒圆，方向键仍按视觉顺序跨行切换。侧栏复制／粘贴调整及底部历史、参数传递操作在同一行放不下时分行排列，不缩字或截断操作名。局部调整标题与蒙版名称分行，名称和操作提示按内容换行，不与状态及预览按钮争用固定宽度或高度。组件在 `DarkroomControls.swift`、`InstrumentFormControls.swift`、`ParameterRow.swift`。

档位旋钮的 `DetentSelector.labelLayout` 默认 `.right`，可传 `.top`／`.bottom`／`.left` 或组合；由调用方决定，不加用户偏好。组合按上／右／下／左顺时针连续分组。文字按半粗体宽度预留，切换不移动引线；档位多或文字长时组件变大，调用方须留足空间。方向键上／左为前一档、下／右为后一档，首尾止挡。

## 工作流布局

- 顶栏使用“图库／编辑”模块琴键；图库内保留网格、单张、比较，切模块不重置查看方式，来源、筛选、活动照片和选择集共用。图库顶部为分组筛选器（文本／属性／元数据／无），条件按分组展开；反斜杠隐藏筛选器但保留查询，“无”关闭过滤但保留条件。零结果页提供清除筛选。
- 编辑的调整工具在照片上、下方独立显示文件名与格式、相机与已有拍摄信息；信息条使用观片底配色，不覆盖图像，不补造缺失元数据。裁剪、污点、蒙版和比较沿用各自画布布局。常规直方图绘图区高 80 pt，剪切控制移至图外；紧凑蒙版仍使用 36 pt 图内控制。暗部与高光各用一颗文字灯键，标签和状态灯都在键面内，不另放眼睛图标或可点击文字。未开启且未按住时灯灭，开启覆盖或按住按键时灯亮，检测结果保留在提示和辅助功能描述中；单击切换覆盖，按住 ⌥ 点按临时查看，松开、拖出、失焦及换照片时恢复原显示。
- 常规照片切换在首帧就绪前保留可用的上一张画布和导航器，编辑立即暂锁。暂锁保留控件的材质、亮度、选中灯、读数和滚动位置；功能本身不可用的控件仍用禁用样式。按键与推子的受限物理反馈保持接通，参数输入、快捷键及辅助功能不能改值；滚动、折叠面板和切图仍可用。
- 侧栏“调整”标题固定，载入反馈集中在不改变布局的状态位：立即显示“切换中”，持续等待 200 ms 后点亮稳定指示灯，连续切图不重新计时；就绪即恢复编辑，不为提示额外延迟。静止读数采用独立的原生绘制层，点击读数转入原生编辑器；绘制层不额外进入读屏树，原生输入框始终保留焦点、数值与禁用语义。
- 编辑控件的保留独立于图像预览：无可用预览、载入失败及重试期间保持已显示的控件；状态帮助和辅助功能明确旧参数属于上张照片。新照片首帧就绪后同步更新数值并恢复编辑，不做整栏淡入淡出。失败时状态位显示错误与重试，旧参数只供显示，不参与当前照片的保存、取样和导出。
- 三个联排实体琴键表示选取、未标旗、排除；评级 0 与五星始终可直接点按，窄窗口分两行。多选混合状态不点亮共同标旗或星级。
- 裁剪页只展示裁剪、拉直、翻转与透视；裁剪／污点／蒙版有固定“完成”，Esc 完成当前工具，R/Q 开关裁剪／污点。有其他所选照片时右下提供“同步…”，先选择参数组。
- 导出使用 860×580 分组表单，左侧预设与分组跳转，右侧单一滚动区；目标位置优先，底栏持续显示摘要、首条阻塞原因与导出按钮。多规格输出在同一父目标下逐规格选预设与子目录。导出预设入口打开表单确认目标，并取得目录授权。
- 相机诊断使用 920×600 原生表单；顶部为文件计数与检查状态，左侧样片列表、右侧当前文件的中性预览和检查明细。空状态说明操作路径，失败状态优先呈现原因；完成检查不等于机型认证，未核验项目在文件标题旁与明细中保留独立标记。选择文件夹与保存报告按阶段使用单一橙色主键。
- 设置使用独立窗口，分外观、缓存与存储、快捷键三类。语言切换在重新打开 App 后生效，其余设置即时生效。
- 菜单分为文件、编辑、显示、照片、窗口、帮助；命令随焦点、所选照片、表单和任务状态变化，文字编辑的撤销留在当前编辑器。
- 预设搜索、收藏、分组用左侧栏实体键和原生菜单；蒙版检查器提供局部参数复制、粘贴与命名预设。颜色标签用 `photoLabel.*` Token，显示为色块键和缩略图标题旁 6 pt 指示点；6–9 快捷键始终可用。
- 窗口高度不足 800 pt 时，蒙版工具使用 36 pt 直方图，保留剪切开关与临时检查，读数通过辅助功能提供；省去独立检查提示行，保留悬停与键盘帮助。人物与部位内容滚动，创建键固定在底部，状态最多三行；44 pt 头像与正文大小不缩小。
